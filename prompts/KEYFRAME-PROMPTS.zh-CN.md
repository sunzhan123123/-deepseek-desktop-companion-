# 房间与六姿态图：中文生成/编辑稿

[提示词入口](README.md) · [下一步：视频](ANIMATION-PROMPTS.zh-CN.md)

这些是静态图制作稿。使用你有权使用的角色参考图，不要求上传原项目的角色图。先锁定一个房间和机位，再编辑状态；不要每张从头自由重画。当前运行素材为1916×1080的完整不透明 PNG，保留同一尺寸与裁切。若工具只能输出标准16:9尺寸，先统一整套画布再制作视频，并按 [自定义教程](../docs/CUSTOMIZE.zh-CN.md) 调整画面专用坐标。

如果平台支持多个参考，明确分工：**房间主图**只定义机位、家具、灯光、透视；**自己的角色图**只定义脸、头发、服装、配饰和比例。以平台实际上传顺序/标签绑定，不要把本文说明性名称直接假定为平台的 `@` 标记。

## 0. 先做房间主图

没有现成房间时可用下面的生成稿。已有自有场景时直接用该场景作主图。生成后检查走路通道、床头小桌和椅子都可用，再继续。

```text
横向16:9的Q版插画卧室，固定正面略俯视机位，画面包含整个房间。前景中央是木书桌，桌后有一把宽圆背木椅；桌面左侧暖黄台灯、笔筒和书，中间一台固定支架上的平板，右侧留出一部手机和杯子的位置。画面后方右侧是一张床，枕头在床头左侧，床头靠近书桌的一侧有小木桌；桌子右侧至床沿之间留出可供角色行走的通道。左侧书架和闭合蓝色窗帘，深蓝紫墙面与木地板。暖黄台灯是固定主光，房间昏暗，床区保留柔和暗部。家具比例清楚稳定，地面与床沿可辨，床和桌不相互遮死。空房间，不出现角色、手机、文字、商标或装饰水印。输出完整画面，不裁掉桌腿和床脚。
```

从选定主图开始，桌子、椅子、床、床头小桌、平板支架、窗帘和灯的位置都不再改变。建议保存一张无人干净底图以便修补角色离座后的区域。

## A：桌前空手待机

输入：房间主图＋自己的角色参考图。保存为 `room-animation-v2/pose-A.png`。

```text
在房间主图中加入角色参考图里的唯一角色。角色参考只定义面部、发型、服装、配饰和Q版身体比例，不带入它的背景。角色坐在前景木椅中央、桌后，两只手自然放在桌面，眼睛睁开看向前方；桌沿和平板正确遮挡躯干，腿和鞋自然出现在桌下。同一部手机平放在平板右侧的桌面，屏幕熄灭。平板固定在原支架上处于工作状态，只有其局部冷光影响附近角色。保持主图完整画布、固定机位、椅子尺寸、全部家具位置、闭合窗帘和暖黄台灯亮度；只加入角色、手机和合理遮挡。完整不透明房间PNG，不能变成人物居中立绘。
```

## B：桌前持手机阅读

输入：已确认的 A。保存为 `room-animation-v2/pose-B.png`。

```text
编辑这张完整房间图，保留同一角色的脸、发型、服装、配饰、身体比例和原位置。角色仍坐在原木椅，自己的左手在画面右侧举起桌面那一部手机，手机屏幕朝向自己，低头阅读；右手自然放回原桌面位置。桌面不再留第二部手机。平板保留原支架、角度和工作状态，手机只在脸和握机手附近增加微弱冷光。完整画布、桌沿遮挡、双腿、家具、闭窗帘、暖黄台灯和整屋曝光不变。只改拿起手机后的姿态和必要局部光。
```

## C：桌前持手机、平板关闭

输入：已确认的 B。保存为 `room-animation-v2/pose-C.png`。

```text
编辑这张完整房间图，仅将平板屏幕关闭，并移除平板造成的局部冷光。保留同一角色的身份、比例、桌前坐姿、低头方向和左手握着的唯一手机，手机屏幕仍朝自己，右手仍在桌面。平板支架、角度和位置不动；手机的少量冷光只在脸和手附近。椅子和桌面不出现新青光，暖黄台灯、昏暗墙面、闭合窗帘和所有家具保持原样，完整画布不裁切、不移动机位。
```

## D：床沿持手机

输入：已确认的 C＋必要时补同一角色参考。保存为 `room-animation-v2/pose-D.png`。

```text
编辑这张完整房间图，把同一角色移到后方右侧床沿坐稳，身体按房间透视自然变小，头身比例、脸、发型、衣服和配饰保持不变。双腿垂在床沿外，双脚落地，右手撑在身旁床面，左手握着同一部手机阅读，屏幕朝自己。书桌后露出完整空木椅，椅子不能变形、移动或换样。平板保持熄屏，桌面和床头小桌都不出现第二部手机。暖黄台灯、闭合窗帘、所有家具、机位、画布和整屋曝光完全保持，手机微弱冷光仅在角色脸和手附近。
```

## E：床上清醒持手机

输入：已确认的 D。保存为 `room-animation-v2/pose-E.png`。

```text
编辑这张完整房间图，只将同一角色改为在原床上沿床长侧卧，头靠枕头左侧，身体朝床尾方向延伸，双腿收在被子下。角色保持清醒，右手托头，左手在脸前握着唯一手机阅读，屏幕朝自己；脸、头发、服装和配饰不变。被子和枕头只在身体接触处形成自然褶皱，不能改变床框、床柱或床尺寸。空椅子、熄屏平板、床头小桌、闭窗帘和暖黄台灯保持原样，手机冷光仅在脸和手附近。完整画布、机位与整屋曝光不变。
```

## F：入睡、手机在床头

输入：已确认的 E。保存为 `room-animation-v2/pose-F.png`。

```text
编辑这张完整房间图，保留同一角色原来的沿床侧卧姿势、头在枕头的位置和被子形状。双眼自然闭合，右手继续托头，左手空手落在被面。把唯一手机放在床头小木桌靠床的右缘内侧，放稳、屏幕熄灭；角色手中和桌面上不再有其他手机，脸上不留手机冷光。角色脸、头发、服装和配饰不变；暖黄台灯始终亮着，平板关闭。床框、空木椅、闭窗帘、全部家具、机位、完整画布和曝光保持原样。
```

## 每张确认后再做下一张

检查同一角色、同一部手机、同一房间、同一裁切。特别比较 B/C 的平板局部光、C/D 的空椅子、D/E 的床沿与被子、E/F 的手机归属；不合格的关键帧会影响所有以它为端点的视频。六张完成后，才开始 [15段视频](ANIMATION-PROMPTS.zh-CN.md)。
