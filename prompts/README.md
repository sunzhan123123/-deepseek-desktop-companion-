# 角色与动画提示词

[返回首页](../README.md) · [换角色教程](../docs/CUSTOMIZE.zh-CN.md)

本目录提供两组中文输入稿：

- [房间与六姿态图](KEYFRAME-PROMPTS.zh-CN.md)：建立统一场景，再编辑 A—F。
- [15段动作与循环](ANIMATION-PROMPTS.zh-CN.md)：10段转场、3段阅读/睡眠循环、2段真实手机打字。

只想重做动画，可直接使用素材包中的 `room-animation-v2/pose-A.png` 至 `pose-F.png` 作首尾帧。换自己的角色时，先替换整套姿态图，再使用同一套动画提示词；“首帧中的同一角色”即绑定你上传的角色，不要求使用当前蓝发角色。

每段单独提交可灵等支持首尾帧的图生视频模式，固定机位，保持完整房间构图。下文的5/10秒是制作建议，不是当前所有文件的实际时长，也不是模型必然精确遵守的参数。选择你实际账号界面支持的模型和首尾帧功能；不要把平台没有的 `@` 标签、开关或命令当作已绑定。

当前已有媒体成片，提示词用于复做与换角色，不是“尚未生成”的清单。新生成结果仍须验证；现有成片也可能在姿态、手机、手部、亮度和循环接点处有可见差异。原始角色参考图与生成账号不在公开包中。

视频调度方法参考 Serge Shima / [smixs/visual-skills](https://github.com/smixs/visual-skills)，[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。本项目据此改写为中文、固定房间单镜头、首尾帧和连续性检查流程。署名不意味着作者为项目背书；该方法参考许可不替代图片/视频素材自己的 [许可说明](../ASSET-NOTICE.md)。
