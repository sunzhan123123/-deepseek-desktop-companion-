# 15段动画：可复制中文稿

[提示词入口](README.md) · [先做姿态图](KEYFRAME-PROMPTS.zh-CN.md) · [运行状态说明](../docs/ANIMATION.zh-CN.md)

适用：可灵等实际提供**图生视频首尾帧**的模式。每段独立提交，使用下面表格对应的现有 `pose-A.png` 至 `pose-F.png`，或你重做后的同名姿态图。首尾帧必须属于同一套角色、房间、尺寸与裁切。固定单镜头，无转场、无运镜、无台词；能关闭自动配乐/音频时关闭。不要把下面的文件路径当作平台已上传的引用，先在界面选择对应图片。

5/10秒是建议起点，不是当前发布片段的实际时长。走路、掀被、探身取放手机若挤不下，优先选较长时长并剪掉多余停顿；不要删掉握稳/放稳的因果。每段正文均可单独复制。负向提示词若平台提供独立栏，可填下面的名词列表；没有该栏则保留正文中的明确连续性约束。

```text
镜头移动，人物瞬移，手机复制，手机换手，额外手指，家具变形，曝光闪烁，字幕
```

## 01｜AB：桌前拿起手机

首帧 `pose-A.png`，尾帧 `pose-B.png`。

```text
固定机位，保持首帧同一角色的脸、头发、服装、配饰和Q版比例。角色坐在原木椅上，左手伸向平板右侧桌面上的唯一手机，手指握稳后拿起，举到脸前，视线随手机转去阅读；右手留在桌面。手机屏幕朝向自己，亮起后只在脸和手附近形成微弱冷光。平板和支架不动，暖黄台灯、闭窗帘、家具和整屋曝光稳定。结束在尾帧的桌前持机姿态并短暂停稳，桌面不再有第二部手机。
```

验收：手机确实从桌面被拿起；先握稳再抬起，结束握机和 B 一致。

## 02｜BA：把手机放回桌面

首帧 `pose-B.png`，尾帧 `pose-A.png`。

```text
固定机位，保持首帧同一角色的脸、头发、服装、配饰和Q版比例。角色坐在原木椅，左手将唯一手机从脸前缓慢放向平板右侧原桌面位置，先接触桌面放稳，再松手收回，双手恢复自然放在桌面的姿态，视线抬回前方。手机熄屏，局部手机冷光随之消退，平板维持原工作状态。椅子、家具、闭窗帘、暖黄台灯和整屋曝光不动。结束精确靠近尾帧，保留短暂停稳。
```

验收：手机在同一桌面落点，不从手中消失；不要直接倒放 AB 代替验收。

## 03｜BC：关闭平板

首帧 `pose-B.png`，尾帧 `pose-C.png`。

```text
固定机位，保持首帧同一角色的脸、头发、服装、配饰和Q版比例。左手全程握住同一部手机阅读，右手抬起轻按平板上沿电源键，随后回到原桌面位置。平板保持同一支架、位置和角度，仅屏幕关闭，照在脸和围裙附近的平板冷光消退；手机仍亮着，局部微光不变。暖黄台灯、闭窗帘、椅子和整屋曝光保持稳定。结束在尾帧的桌前持机、平板关闭姿态，短暂停稳。
```

验收：右手有按键动作；关闭的是平板，不是手机或台灯。

## 04｜CB：唤醒平板

首帧 `pose-C.png`，尾帧 `pose-B.png`。

```text
固定机位，保持首帧同一角色的脸、头发、服装、配饰和Q版比例。左手始终握着同一部亮屏手机，右手抬起轻按平板上沿电源键，随后落回原桌面位置。平板只恢复屏幕工作状态，不旋转、不合上支架，局部冷光柔和恢复到脸和衣服附近。角色继续看手机，家具、椅子、闭窗帘、暖黄台灯和整屋曝光不变。最后回到尾帧的桌前持机姿态并短暂停稳。
```

验收：平板位置不变；光的变化局限于屏幕附近。

## 05｜CD：从桌前走到床沿

首帧 `pose-C.png`，尾帧 `pose-D.png`。

```text
固定机位，保持首帧同一角色的脸、头发、服装、配饰和Q版比例，左手全程握着唯一手机，屏幕朝自己。角色先侧身从椅子画面右侧离座起身，双脚交替迈步，沿桌子右侧通道绕开床头小桌，走到后方床沿坐稳，双脚落地，右手轻撑床面。走远时按透视自然变小，椅子原地不动。平板全程关闭，手机微弱冷光只随手机照亮脸和手，不留在空椅子、桌面或平板上。暖黄台灯、闭窗帘和整屋曝光稳定。结束匹配尾帧并停稳。
```

验收：真正侧身离座、交替迈步、坐稳；空椅和平板不留新增青光。现有 CD 曾按此方向重做和调色，仍以新成片为准。

## 06｜DC：从床沿走回桌前

首帧 `pose-D.png`，尾帧 `pose-C.png`。

```text
固定机位，保持首帧同一角色的脸、头发、服装、配饰和Q版比例，左手全程握着唯一手机。角色从床沿用右手轻撑起身，双脚交替迈步，沿桌子右侧通道绕开床头小桌，走回椅子画面右侧，侧身入座并坐稳，右手回到桌面。走近时按透视自然变大，头身比例不变，椅子原地固定。平板始终关闭，手机冷光只在角色附近；暖黄台灯、家具、闭窗帘和整屋曝光稳定。结束匹配尾帧，保留短暂停稳。
```

验收：行走方向与 CD 对应；不穿过桌面、椅背或床头小桌。

## 07｜DE：从床沿躺到枕边

首帧 `pose-D.png`，尾帧 `pose-E.png`。

```text
固定机位，保持首帧同一角色的脸、头发、服装、配饰和Q版比例。左手全程拿着同一部手机，右手支撑床面并掀开被子，角色把双腿收进被下，沿床的长度靠向枕头，头停在枕头左侧，身体朝床尾延伸，轻轻侧卧。右手恢复托头，左手举手机阅读，屏幕朝自己。被子只在身体接触处自然起伏，床框和枕头位置不变。平板关闭，暖黄台灯与手机局部冷光稳定，闭窗帘不动。结束匹配尾帧并停稳。
```

验收：腿进入被下的过程可读，身体沿床而非横穿床框；手机持续由左手持有。

## 08｜ED：从枕边坐回床沿

首帧 `pose-E.png`，尾帧 `pose-D.png`。

```text
固定机位，保持首帧同一角色的脸、头发、服装、配饰和Q版比例。左手始终拿着同一部手机，右手从托头位置移到床面支撑并掀开被子。角色先坐起，把双腿移出被子，转向床侧坐到床沿，双脚落地，右手停在身旁支撑。被子自然落回床面，床框、枕头和家具不移动。平板关闭，暖黄台灯、手机局部冷光、闭窗帘和整屋曝光稳定。结束匹配尾帧的床沿坐姿，短暂停稳。
```

验收：先起身再移腿，最后双脚在床外；不把床被变成衣服或改变手机数量。

## 09｜EF：放下手机入睡

首帧 `pose-E.png`，尾帧 `pose-F.png`。

```text
固定机位，保持首帧同一角色的脸、头发、服装、配饰和Q版比例。角色右手从托头改为撑床，上身向画面左侧床头小桌侧转探身，左手把唯一手机放到小桌靠床的右缘内侧。手机先接触桌面放稳，手指再松开，随后角色退回枕头，右手重新托头，左手空手落在被面，双眼缓缓闭合。手机熄屏，脸部手机冷光消退；平板关闭，暖黄台灯、家具、闭窗帘与曝光保持稳定。结束匹配尾帧的睡姿并停稳。
```

## 10｜FE：醒来取手机

首帧 `pose-F.png`，尾帧 `pose-E.png`。

```text
固定机位，保持首帧同一角色的脸、头发、服装、配饰和Q版比例。床头小桌上的唯一手机先亮起，角色睁眼，右手撑床，上身朝小桌探身，左手先握稳手机再拿起，随后退回原枕边侧卧。右手恢复托头，左手举手机阅读，屏幕朝自己。微弱冷光跟随手机从桌边移动到脸和手附近，不照亮整间房。平板关闭，暖黄台灯、家具、被子和闭窗帘稳定。结束匹配尾帧的清醒持机姿态并停稳。
```

验收：手机来源明确，握稳后才离桌；不是手机凭空出现在手中。

## 11｜loop-B：桌前阅读循环

首尾均用同一张 `pose-B.png`。

```text
固定机位，保持首帧同一角色的脸、头发、服装、配饰和Q版比例。角色坐在原椅子上，左手稳稳持同一部手机阅读，右手始终放在原桌面位置，不点按手机。只表现一次自然眨眼、极轻微呼吸和视线在屏幕上的小幅移动，手机角度和手的位置稳定。平板保持工作状态，暖黄台灯与屏幕局部冷光恒定，家具和闭窗帘不动。动作完成后回到首帧姿态与呼吸阶段，首尾可循环。
```

验收：这是阅读，不应有连续输入动作；重复播放两遍检查头、手和亮度跳变。

## 12｜loop-E：床上阅读循环

首尾均用同一张 `pose-E.png`。

```text
固定机位，保持首帧同一角色的脸、头发、服装、配饰和Q版比例。角色沿原床侧卧，右手托头不离开，左手稳定举着同一部手机阅读，不点按输入。只表现一次自然眨眼、极轻微呼吸和视线在屏幕上小幅移动，被子随呼吸轻微起伏后复原。头、手机、枕头和床框位置稳定。平板关闭，暖黄台灯与手机局部冷光恒定，家具和闭窗帘不动。结尾恢复首帧姿态与呼吸阶段，方便连续循环。
```

验收：托头手稳定、手机唯一；不要让循环逐次坐起或移动被子。

## 13｜loop-F：睡眠循环

首尾均用同一张 `pose-F.png`。

```text
固定机位，保持首帧同一角色的脸、头发、服装、配饰和Q版比例。角色一直闭眼保持原侧卧睡姿，右手托头，左手空手落在被面，只做一轮极轻微呼吸和对应的被面起伏，然后自然回到起始阶段。头、双手、枕头和手机位置固定，唯一手机始终熄屏放在床头小桌，平板一直关闭。暖黄台灯亮度、昏暗房间、闭窗帘和全部家具稳定。结尾恢复首帧，不睁眼、不伸手，首尾可循环。
```

验收：闭眼、空手、床头手机和呼吸周期首尾一致。

## 14｜typing-B：桌前真实手机打字

首尾均用同一张 `pose-B.png`；输出到 `companion-typing-v1/B.mp4`。

```text
固定机位，保持首帧同一角色的脸、头发、服装、配饰和Q版比例。角色坐在原木椅，左手全程稳稳握着同一部手机，手机屏幕朝自己，位置和角度稳定。角色抬起原本放在桌面的右手，用右手食指在朝向自己的手机触屏上连续点按，手指从屏幕侧接触而不是敲手机背面，清楚表现输入回复。完成后右手放回原桌面位置，恢复首帧阅读姿态并短暂停稳。视线始终看手机，平板保持工作状态，家具、闭窗帘、暖黄台灯和屏幕光稳定。
```

验收：确实点按触屏，完成后右手回桌面；只有手机摇晃不合格。

## 15｜typing-E：床上真实手机打字

首尾均用同一张 `pose-E.png`；输出到 `companion-typing-v1/E.mp4`。

```text
固定机位，保持首帧同一角色的脸、头发、服装、配饰和Q版比例。角色保持原床上侧卧姿势，左手全程稳稳拿着同一部手机，手机屏幕朝自己，位置和角度稳定。原本托头的右手移到手机旁，用右手食指在朝向自己的触屏上连续点按，手指从屏幕侧接触而不是敲手机背面，清楚表现输入回复。完成后右手回到原托头位置，恢复首帧阅读姿态并短暂停稳。上身、床被、枕头与家具稳定，平板关闭，暖黄台灯、手机光和闭窗帘不变。
```

验收：托头手有离开、输入、返回三阶段；左手始终持同一手机。

## 统一验收和最小返工

每段先确认“起点事实 → 可见动作 → 落点事实”。锁定镜头与环境光；手和手机是主要视觉焦点，手机冷光是各段共同的视觉线索。每段只完成一个状态变化；不要为了“更生动”另加镜头移动、走近镜头或新的道具。

连接时比较上一段末帧、对应姿态图和下一段首帧，检查角色比例、握手机的手、手机数量/朝向、家具与床被、光源和曝光。循环至少连播两遍，打字还要连到阅读与下一转场。已生成视频的起止帧即使接近，也可能有可见跳动；程序预载无法修复生成内容中的缺口。

有问题先只重做失败片段：走路漂移先改 C/D 两端和离/入座，床上动作先改 D/E 接触关系，放取手机先改 E/F 的落点与握稳顺序；亮度漂移先锁台灯与手机局部光。不要把某段“待验证”的生成结果写成全部动画已无缝通过。
